## 已知风险

运行时依赖npm audit --omit=dev报告0项告警（仅当次数据库结果，不代表绝对安全）。构建依赖 npm audit 有8项 moderate 传递依赖告警（electron-builder/@electron/get相关链）；未采用破坏性强制升级。当前不把构建工具告警报告成实际远端攻击，也不宣称审计无告警。正式发行前需在保持 Electron 打包可用的条件下复核修复。

用户无需再次提供原版安装包。本地已有英文 Steam GOTY 资源足够继续研究。实际服务验收需用户在本机设置中填入有额度的 DeepSeek 与另一服务商 Key；无需将 Key 发给开发者或聊天。真实语音和所有原版逐帧实机验收仍需实际运行环境，不能以本地夹具替代。

## 后续阶段门槛

1. Phase 1收尾：原版各指定高度、商店/字体/气泡、连续动画和音频采集；与共享播放器逐元素/关键帧对比，记录误差及修复。
2. Phase 2收尾：DeepSeek+另一兼容接口实际多轮/流式/usage对账；长文与原版对白抢占；30题人格人工评价。
3. Phase 3收尾：实际系统语音/云TTS/云STT、权限拒绝/打断/分页；默认音色与本地STT方案许可及体积评估；彩蛋逐项实机参考。
4. Phase 4收尾：NSIS安装/升级/卸载、不同窗口/浏览器、跨端迁移、损坏和配额、硬件性能与依赖审计；全部通过才改为正式发布。
