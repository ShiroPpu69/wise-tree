# 0.1.3 界面、名称、图标与语言更新

用户要求在现有工程上改进，保留游戏/经济/API架构。当前正式显示名称为“智慧树 / Tree of Wisdom”。保留原应用ID与历史用户数据目录以避免更名清空旧存档；内部兼容路径不作为UI名称显示。

## 原版资源与图标

tools/build_tree_icon.py直接解码本机原版TreeOfWisdom.reanim.compiled的anim_grow20末帧，将可见树干、覆盖层与叶片依原始仿射矩阵合成；排除背景、草地独立层及控制轨道，没有AI图片或截图抠图。树干本身的根部像素保持原样，不添加装饰。透明PNG和16/20/24/32/40/48/64/128/256 ICO只保存在private/branding；provenance.json记录帧、轨道和SHA。个人包额外包含图标供BrowserWindow使用。Windows资源编辑开启，代码签名关闭；安装/卸载图标、快捷方式、EXE、窗口使用同源图标。未购买签名证书。

## 设置与输入栏

只保留原版OPTIONS设置入口；底部只有输入、发送、记录及按需出现的语音/取消。统一设置包括常规、AI模型、语音、对话与记忆、游戏五页。原版Dialog九块与Button三块图像直接用于面板/按钮，按实际左右不同宽度和上下不同高度拼接，拼接处覆盖2px以避免浏览器分数尺寸采样露缝；调整输入栏大小、间距、颜色与文字。勾选框直接使用原版OPTIONS_CHECKBOX0/1（42×39），滑块使用OPTIONS_SLIDERSLOT（135×10）和SLIDERKNOB2（22×29），不是CSS画图代替。旧资源缓存缺少这些项时个人包自动重新解析内置PAK，不重置存档。原生菜单默认隐藏，F11仍可切换全屏。

设置不再要求先配置LLM才能保存常规、语音或人格。游戏页保留原有兑换与存档操作，不提供测试奖励入口。原版场景、成长算法和原始固定台词仍采用此前已验证路径。

## 字体与语言边界

本地英文Steam GOTY字库审计只有Latin1，未找到原版中文字体。英文游戏场景继续用原版位图字体；HTML扩展控件和场景缺字使用随包ZCOOL KuaiLe（站酷快乐体），不再依赖微软雅黑/Arial。场景中文按同一字体实测宽度分页，原版轮廓层位置不变。当前UI文字的中文字形覆盖检查无缺字；任意用户输入的罕见字/其他文字仍可能触发系统后备字体，不宣称覆盖全部Unicode。

SHA-256：812a6fc1fe54b6d73a419245c32dfeba8aa33104d5be90d1cf6af082007cb71d。

SIL OFL 1.1全文保存在assets/fonts/OFL.txt，随THIRD_PARTY_NOTICES分发。它是合法补充字体，不是找到的原版中文字库。

packages/i18n-core集中管理中英系统文本，React本地化不修改用户/模型内容或编辑框值；原版固定游戏提示是英文资源内容，尚无经过版本验证的官方中文台词包，保留原文。SHOP/OPTIONS等嵌在原版美术中的英文不重绘。语言偏好默认简体中文、即时保存，重启/导入后恢复；Windows标题与原生菜单同时切换。系统错误及动态usage使用集中映射。AI默认回复语言随界面，用指令明确允许用户指定其他语言；最终模型行为仍需真实服务验收。

## 实测与限制

tests/ui-settings-browser.mjs检查唯一入口、五页、中英切换及重载、逐页无遗漏中文系统标签、1080×840和800×600布局。tools/audit_i18n.mjs检查错误字面量翻译覆盖。协议/经济、施肥优先级、存储并发/快照和语音协议继续回归。

tools/install_ui_trial.ps1验证实际安装归档、注册项、桌面/开始菜单快捷方式和PE图标提取。tests/installed-ui.mjs启动实际安装EXE（app.isPackaged=true），用独立配置检查默认中文、无需导入、字体、持久语言/窗口标题、真实SSE与usage协议（本地模拟服务，非真实服务商）。普通GPU模式的原生窗口已观察到场景和新图标；SwiftShader测试模式下Windows捕获曾显示空白客户端，但CDP截图正常，未将其当作原生截图通过。游戏默认没有强制SwiftShader。

本轮消息未附带所说三张截图，无法声称完成与三张用户图逐项对照。已有原版实机对照证据继续保留，未将新增设置面板宣称为原版已有界面，也未宣称完成全场景≤2像素验收。
