# 智慧树 0.1.6 个人试用版说明

更新：2026-10-21。此版本可试用，不是全部需求验收完成的正式版。

## 安装和第一次启动

安装程序：`F:\vibecoding\wise-tree\private\releases\personal\智慧树 安装程序 0.1.6.exe`，约139 MiB，Windows x64。名称为“智慧树 / Tree of Wisdom”，使用原版树形透明图标，未购买代码签名证书。这是给资源所有者本机试用的个人包，包含已核对的原版资源，不公开发布。

安装完成后直接打开应用，无需选择或导入原版资源，也无需启动原版游戏。程序自动从随安装提供的资源完成首次本地准备；之后直接加载缓存。即使原版游戏安装目录不可访问，仍使用包内资源。缓存缺失或不兼容时自动重新准备，保留游戏存档。包内资源损坏时提示重新安装，不要求用户寻找main.pak。

树从1英尺、5袋树肥、0金币开始。点击左上角树肥，再点击场景施肥；每次消耗1袋并长高1英尺。高树保持树干视角，不自动缩放。

## 接入自己的模型

点击右上角 选项 → 对话模型，选 DeepSeek、Kimi 或智谱，填写自己账号可用的模型名称和 Key，保存并测试连接。Key 只填本机应用，不发送到聊天。连接测试也可能产生服务商费用。模型列表接口并非所有账号都支持，可以直接手填模型。底部不再另设设置入口。

选项的“常规”页可切换简体中文和英文、切换全屏、开启原版音效。语言立即保存，重启保持；AI默认回复语言跟随界面，用户在聊天中指定其他语言时优先遵循。另有语音、对话与记忆、游戏分页。存档导入/导出和兑换比例在游戏页。

不同模型支持的参数不同，若服务商明确提示参数不兼容，可在专业配置中关闭 temperature、top_p 或输出上限，或按其要求切换输出上限字段。诊断信息应先删去私人聊天、账号信息，再反馈。不要发送 Key、凭据文件或完整个人数据库。

本轮真实服务验收计划为 DeepSeek 加 Kimi 或智谱；当前通过的是本地协议夹具测试，没有声称这些服务已经实际接通。

## 金币和保存

默认每20000个服务商确认的 Token 发放2500金币；剩余进度保留。没有可靠 usage 时不发奖励。到商店 用2500金币买1袋树肥，确认后才扣款；库存最多10袋。聊天不会自动施肥。

正常操作自动保存。选项可以导出不含 Key、游戏媒体的存档；资源重新导入不会清空树高和金币。0.1.1额外保留最近3个游戏事务快照，检测到主记录损坏时尝试恢复；不会额外保留已删除的聊天或记忆内容。自动快照不能代替独立导出备份。

如已经试用旧版本，运行新版安装程序即可保留原应用数据目录。0.1.4会将旧的默认兑换比例2000→2500迁移为20000→2500，保留已有金币与未兑换进度；自定义比例保持原样。迁移只执行一次，不重新计算已发金币。升级后避免用旧版本打开同一数据目录。

## 建议试用内容

1. 安装后直接进入场景，施肥一次，退出重开，确认2英尺、4袋肥料。
2. 配置自己的模型，连续聊两轮，检查流式气泡、滚轮阅读和“记录”。
3. 检查用量进度；达到兑换条件后，购买树肥，再亲手施肥。
4. 主动保存一条普通偏好，重启后查看记忆、再删除。
5. 桌面版默认开启免费系统朗读和本机识别；点击“说话”录音，再点击“结束录音”，识别后先进入草稿。语音页可试听、关闭或改用自定义服务。

反馈请包括版本、具体操作、预期和实际结果；如有截图，先遮挡私人内容。正式存档没有开发者奖励入口，无需为了测试1000英尺消耗付费Token。

## 目前主要限制

- 真实双服务商、多轮账单对照和30题人格评价未通过。
- 真实麦克风/第三方语音听测未通过；桌面系统语音取决于Windows已安装音色，没有固定内置音色包，使用本机已安装系统音色及识别器。
- 全部指定高度、动画与声音同步、全场景≤2逻辑像素对照仍待完成。
- 汉化补丁内中文字形页已找到但映射尚待验证，中文暂用随包站酷快乐体补充字体，英文场景保留原版位图字体；原版MO3背景音乐播放器尚未实现。
- 彩蛋为独立原版素材演示，不是完整战斗场景。

完整证据与限制见[测试记录](validation.md)和[实现状态](implementation-status.md)。
