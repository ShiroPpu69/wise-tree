## 证据分级

- **L：本地实测**，包括目录检查、合成样本测试。合成样本不是原版素材。
- **R：公开源码事实**，固定提交中确实存在的逻辑。可能混合版本、包含修复，不能直接提升为 GOTY 事实。
- **A：作者报告**，README 或搜索索引中的声称，未由本地游戏复验。
- **P：建议或推测**，供后续验证，不是原版事实。
- **G：用户自有 GOTY 实证**，需要版本、文件哈希、运行或资源证据。本轮 G 类证据为零。
- **U：用户确定的产品规则**，如初始 1 英尺、5 袋、兑换比例、库存 10、保留树干视角。它们是实现约束，无需伪装成研究结论。

### 已核实的格式线索（R，另有 L 合成验证）

1. PopCap PC PAK：整体 XOR `0xF7`；解码头 `0xBAC04AC0`、版本 0；目录项带路径、长度、FILETIME，表后连续数据。PAK 可读不能认证版本。[PAK 参考实现](https://github.com/lmintlcx/pvztools/blob/46512f3b2a62f8f477814326ae900c65847f5485/src/pak.cpp#L110)。
2. PC compiled Reanim：可有 `0xDEADFED4`、声明解压长度、zlib 包装；轨道变换和 image/font/text 引用。它不是通用 XML，不能解压后直接交给 XML 解析器。[PC 编解码](https://github.com/PopGameTool/PopStudio/blob/a8bd1edd3e1dc4ec79e3b37ee29774e268438d85/PopStudio.Shared/YFTYLib/Reanim/PC.cs)。
3. 文本 `.reanim` 与 compiled 是不同表示；运行时还包含轨道分组、播放范围、缺省值继承等语义。只转 PNG 或导出时间轴不足以还原场景。[Reanimator](https://github.com/Patoke/re-plants-vs-zombies/blob/c4692036c5e11d227c8fb7c593b734dac96da028/Sexy.TodLib/Reanimator.cpp)。

## B. 原版素材提取与转换方案

完整候选映射见 [asset-mapping.md](asset-mapping.md)。当前每项均为未导入，不存在“提取成功”的真实素材。

流程建议（P）：

1. 用户选择自有安装目录或 Web 文件集合；只读读取并生成版本/散列清单。保留原始大小写、编码、原包来源及外置覆盖文件，不能先把多版目录混成一个素材池。
2. 验证目录表、数据区边界、归一化重复名、危险路径和大小限制。先清单后提取，输出到私有暂存区；不运行游戏 EXE、DLL 或任意包内脚本。
3. 按 `properties/resources.xml` 的 ID、路径、字体、行列、alpha/颜色图配置解析引用闭包；compiled 动画引用须递归解析，不能仅凭 ID 转小写猜文件名。
4. Reanim 生成无损中间表示：保留所有轨道顺序、每帧八通道、缺省哨兵、image/font/text、标签、贴图子帧、源帧率与运行时控制项；转换器版本进入 manifest。Godot `.tscn` 仅作为候选对照输出。
5. 图片保留原始版本，验证 JPG+alpha 组合、GIF 调色板、预乘 alpha、采样和半像素。转换目标是无损 RGBA PNG/图集及映射，不拉伸、重绘、AI 补画或截图抠图。
6. 字体保留字符映射、advance、kerning、offset、ascent、层顺序、颜色/描边和图集；先建立专用 bitmap font renderer，再评估 BMFont 是否能完整表达。中文编码/缺字必须按实际语言包测量。
7. 音效先探测文件头与资源引用。OGG 可候选直用；AU 视编码转换；MO3 需要合适解码器及许可核查，不能承诺 ffmpeg 直接支持。不得把依赖原版 bass.dll 作为独立应用的默认运行方案。
8. 粒子/拖尾同时保留 compiled 和无损参数，不接受只有近似 Godot 输出。任何未实现语义形成明确缺失项。
9. 转换完成后做引用完整性、图像/字体/声学检查和原版对照；通过才原子发布本地资源集。中途失败不破坏前一可用资源集。

本轮工具只实现步骤 1/2 的部分只读检查和 PC Reanim 元数据探测；正式解包、清单 XML 解析、音频转换与导入 UI 尚未实现。

## D. 建议技术架构

建议保留 TypeScript + React + Vite + PixiJS + Electron，作为 **待真实动画验证的首选**，没有宣称已经选型验收。完整目录和理由见 [architecture.md](architecture.md)。

Reanim 需要两个独立角度、非均匀 scale、平移及离散图像/可见性。Pixi 的 Matrix/场景图能表达仿射变换和分层，适合共享 Web/Electron 播放器；它没有自动提供 PopCap 语义。Godot 也需要转换器或专用 runtime；现有转换能写出 tscn，不代表忠实智慧树和粒子。

P：先做只含原资源的最小播放器，逐帧对照矩阵、混合、裁切和时序；若出现无法解决的 Pixi 兼容问题，再用同一输入/测试比较 Godot。此次未安装/运行 Pixi 或 Godot 引擎，无 FPS、显存、内存或像素误差结果。

## F. 待解决问题与风险

1. **版本身份**：无 GOTY EXE/PAK；无法证明来源、语言、改版与否。第一道门槛。
2. **视觉核心**：无原版 Reanim/纹理，不能确定成长段帧数、变换/裁切、树冠移出时间和高树干绘制方式。
3. **中文覆盖**：原版字图有限，AI 可输出任意 Unicode。必须审计字体覆盖；不足时记录缺字，并与用户明确备用字体方案，不静默冒充原字体。
4. **代码差异**：公开反编译混合版本、加入修复；没有完整函数地址/二进制匹配证据。不能作为逐像素真值。
5. **转换缺失**：图片 alpha、粒子、混合、文本、轨道标签启发式等会使“校验通过”失真。自校验与原版实证需独立。
6. **台词/音效**：不知道实际本地化全文和资源映射。不能生成默认原版台词库或承诺固定原版声音。
7. **API/Web**：CORS、缺 usage、断流/重试不确定用量必须明确处理；不能默认上传 Key 到第三方代理。
8. **默认语音**：系统 TTS 不能保证固定音色；内置离线模型需进一步做许可、包体、CPU/内存与中英文验证，目前没有合格的“内置默认音色”交付。
9. **本地数据**：浏览器存储可能被清理；导出备份、持久存储申请、恢复路径需测试，不宣称绝对不丢数据。
10. **公开发行**：代码许可证选择与第三方归属清单尚未最终确定；游戏素材与用户数据一律私有，不加入默认发行物。

## G. 下一步行动及最少配合

最省事：提供**你合法拥有、未改动的 PC GOTY 安装目录的本地路径**。本任务没有要求上传公共网站；可以放到 `private/original/`。优先需要：

1. `main.pak`（原文件）；
2. 该安装的游戏 EXE（常见 `PlantsVsZombies.exe` 或 `popcapgame1.exe`，以实际为准），仅检查版本/哈希和后续静态研究，不自动执行；
3. 若安装根目录有外置 `properties/`、`data/`、`images/`、`reanim/`、`compiled/`、`particles/`、`sounds/` 或本地化字体目录，请一并保留原层级，避免漏掉包外资源；
4. 发行来源/版本/界面语言说明，以及是否做过汉化、替换 main.pak 或修改 EXE。

**首批不必提供存档、API Key 或全套录像。** 若目前只有 main.pak，也能先开展解包与动画审计，但 GOTY 身份仍需补版本证据。若无法提供 EXE，可先给文件属性中的版本和 SHA-256；部分逻辑仍会保留未验证状态。

随后可选：用户备份存档（只操作副本）、800×600 客户区无缩放无损截图/录屏，覆盖 `1,2,5,6,10,20,30,40,49,50,51,99,100,101,500,1000,1001`。重点录制跨界施肥、50 以上重进、商店缺币/满库存。详细可复现实验见动画文档。不能实际运行原版时，可由用户按该实验录制；截图只作对照，不成为正式素材。

收到文件后，立即只读清点和哈希 → 解包审计 → 列动画标签/引用/帧数 → 帧变换导出与原版对照 → 更新所有候选映射的实际状态。只有关键原版素材、绘制与成长通过验证，才开始 Phase 1。
