## 研究档与原用户数据

在任何研究写入之前，已备份Steam本地存档目录到 `private/original-runtime/save-snapshot-before-observation/`。原玩家未拥有智慧树，因此通过游戏本身新增本地研究玩家 **WISDOMLAB**，对应 `user2.dat`。这不是应用未来的开发者模式，也不是新在线账户。

游戏关闭后，`tools/prepare_runtime_profile.py` 校验 users.dat 版本14和 WISDOMLAB/id2映射、详情版本12、长度888、调用时指定的完整SHA-256，先保存原始和准备后副本，再仅修改user2的6个已核查字段。未编辑原玩家user1或共享users.dat。研究档赋予解锁状态、49英尺、5袋和研究金币，只为原版验证，不经过真实AI消耗。

| int32偏移 | 意义 | 准备值 |
|---|---|---|
| 0x04 | 关卡 | 4 |
| 0x08 | 内部金币（显示×10） | 10000 |
| 0x0C | 完成冒险 | 1 |
| 0xD4 | challenge[49]树高 | 49 |
| 0x20C | purchase[27]拥有智慧树 | 1 |
| 0x210 | purchase[28]树肥编码 | 1005 |

准备日志和前后副本位于 `private/original-runtime/profile-preparation-49/`。脚本不自动判断进程是否已退出，必须先从原版UI关闭游戏；它是版本限定的研究工具，不能用于未知构建或正式导入器。

观察完成后已从游戏UI恢复原玩家选择并关闭原版，研究档保留在游戏玩家列表。原玩家的关卡、金币、通关、树高、树购买、肥料6项前后相同。原玩家文件整体字节有变化，不能声称整个存档完全未变；正常运行会更新其他字段，本轮没有判定每个差异的意义，也没有用旧备份覆盖它。原游戏EXE/PAK未编辑。

直接运行安装EXE曾出现Steam.dll错误；通过现有Steam的开始游戏入口成功。没有复制DLL、修改启动器或绕过Steam。

## PixiJS 研究播放器

路径 `research/reanim-lab/`。这是单独的800×600研究画布及画布外开发控件，不是正式产品界面。无React产品UI、AI、交易账本或正式存档。

从本地提取目录导出3份Reanim完整轨道、41个真实图片引用、2个原声音到 `private/reanim-lab-assets/`。播放器保留独立kx/ky仿射变换、稀疏字段填充、离散纹理选择、具名动画段、6条独立云实例、前后景层次和施肥状态锁。加载段夹到50，成长段夹到51；高树不缩放。调度与插值仍属待对照的研究实现。

```powershell
python tools/export_reanim_lab.py private/extracted/steam-goty-1.2.0.1096
cd research/reanim-lab
npm ci --ignore-scripts
npm test
npm run build
npm run dev
# 另一终端、相同目录：
npm run test:browser
```

只绑定 `127.0.0.1:5178`。浏览器测试使用本机Chrome固定路径（其他机器须调整），报告写入private。Vite的publicDir和build输出都涉及私有媒体，**private/reanim-lab-dist不可公开部署或发行**。公开代码不包含素材。

| 已执行检查 | 实测结果 | 局限 |
|---|---|---|
| TypeScript严格检查与Vite构建 | 通过 | 不是Windows安装包 |
| 研究核心测试 | 6/6通过 | 不替代原版规则验收 |
| 浏览器高度 | 19个：1、2、5、6、10、20、30、40、49、50、51、99、100、101、499、500、999、1000、1001 | 此项是播放器状态与矩阵检查 |
| 施肥转换 | 8组指定转换；每次扣1袋，重复feed拒绝 | 真实游戏只实际测了49→50和50→51 |

浏览器结果：`private/reports/reanim-lab-browser/result.json`，Chrome155.0.8059.82、Pixi8.22.0，ANGLE/SwiftShader软件WebGL。106次绘制+诊断采样中位0.60ms、p95=3.80ms；不含完整帧/GPU提交耗时，不用于承诺设备性能。Godot只完成转换器实验，未实际启动引擎，暂不能做公平性能比较。

49加载/51重进的JPEG归一化后，对树干、树根、草地三个预定ROI各搜索±3整数像素，6处最佳整体平移均(0,0)，RGB平均绝对差约0.75…2.96（0…255）。记录 `private/original-runtime/registration-diagnostic.json`。这是局部整体配准诊断；不证明所有轮廓/控件均≤2px，也不消除JPEG、缩放及采样差异。
