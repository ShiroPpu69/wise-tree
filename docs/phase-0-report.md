## C. 智慧树生长机制

本构建Init选grow1…50，Grow先加高度再选grow1…51；肥料有独立动画，工具动画结束后触发成长；防重入与离开场景补完路径均已静态定位。

grow49为332…334帧；grow50为335…344，在340由tree8切换到本身已无树冠的tree9树干图；grow51为345…353，复用tree9做拉伸回落。以后数值继续长高，段号夹到51；不引入zoom或线性高度缩放。

81个树相关字符串键已提取，其中80个数字对白。100/500/1000的固定键为800/900/1000，对应daisies/dance/pinata；>1000用1100。完整原文仅存私有库。

本地库存检查是>=10，纠正公开P参考实现>10的版本误用。树肥内部价250，货币格式乘10，显示2500。
