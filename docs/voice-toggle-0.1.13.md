# 0.1.13 回复语音开关

底部在「发送、记录、说话」右侧增加第四个原版石质按钮，显示当前状态「语音开 / 语音关」，支持键盘操作及中英文切换。关闭立即停止当前朗读，取消待播放任务，阻止迟到的合成结果、手动试听和继续播放；文字对话继续正常接收。开启后，后续回复自动朗读，采用现有的语音来源和音色配置。

开关自动保存，重启后保留。旧存档默认开启，保留原来的自动朗读偏好；首次点击开启会启用自动朗读。快捷按钮只保存开关及开启时的自动朗读选项，不会顺带保存高级设置中尚未提交的草稿。设置 → 语音也提供同一个总开关。关闭朗读不会关闭「说话」麦克风输入，不改变游戏音效。已提交到远端的合成任务可能仍由服务端完成，但不会再播放。

64 项单元测试通过，包括旧存档兼容、关闭时取消当前及预取音频、迟到结果隔离、各类语音来源的关闭拦截。真实 Electron 包的隔离测试使用本地模拟流式模型及随包合成参考 WAV，验证实际 HTML 音频播放与立即停止、关闭期间不发起语音请求、重新开启后朗读、刷新保持、键盘及英文、麦克风配置保持。该测试不调用外部语音或付费模型，不代表外部服务可用性验收。证据位于 private/reports/voice-toggle；安装版结果以 installed.json 为准。

四按钮在 1080×840、880×700、720×580、480×480 窗口下均检查边界和间距，发送取消时保持四按钮。输入框随之缩短；木质背景及按钮拼缝修正保留。游戏、金币、用量结算逻辑未改动，模拟对话累计 6000 用量仍为零金币（默认 20000 一次）。

## 0.1.14 默认状态调整
按用户要求，全新安装默认「语音关」，旧配置缺少总开关字段时也默认关闭。已明确保存的开启或关闭选择保留，不会在每次启动时重置；用户点击「语音关」即可开启后续回复朗读。
