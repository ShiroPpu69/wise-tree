# 0.1.8 免费联网成长语音

Windows 默认选择联网朗读，无需用户语音密钥或额外下载模型。文字直接发送至微软 Edge Read Aloud 服务；没有自建中转，不上传整份聊天记录。使用第三方 MIT 客户端 [MsEdgeTTS](https://github.com/Migushthe2nd/MsEdgeTTS)，非微软正式承诺的免费开发 API，可能限流、失效或变更。失败仅停止朗读，文字和游戏继续使用；不会自动转向付费服务。

## 成长阶段

| 高度 | 阶段 | 中文音色 |
| --- | --- | --- |
| 1–9 英尺 | 儿童 | zh-CN-YunxiaNeural |
| 10–49 英尺 | 年轻 | zh-CN-YunxiNeural |
| 50 英尺起 | 老年阶段，沉稳男声 | zh-CN-YunyangNeural |

“老年阶段”是本应用角色阶段，不能解释为服务商对该声音年龄的官方标注。语音设置可修改两个分界高度或固定音色。每条回复开始时固定阶段，避免一句话中途换声。英文界面使用对应英文音色，中文三种音色已经真实联网合成验证；英文音色尚未独立听测。这些声音不是 GOTY 原版配音。

## 延迟与体积

收到 LLM 的完整句子就开始合成，不必等待整个回复结束。当前句播放时预取下一句，串行播放，支持暂停、继续、停止；施肥会终止当前朗读。代码块和链接不会机械朗读。实现是短片段 MP3 合成及预取，不是音频流式边接收边解码。

不再打包 Qwen 模型和本地推理运行库，安装包从 0.1.7 的 1,578,424,970 字节降至约 146 MB。旧私人研究模型仍可保留于开发目录及旧版本备份，不进入新安装包。实际 NSIS 升级已验证清除安装目录中的 neural-voice。

## 验证与限制

51 项单元测试通过。`tests/online-voice-live.mjs` 验证三个中文音色、输入约束、取消及 XML 转义。`tests/online-voice-desktop.mjs` 使用真正安装后的 EXE 和免费网络语音，LLM 是明确标记的本地模拟流，验证提前朗读、句间预取、三个阶段、暂停停止、高度阈值保存、窗口布局及精确用量只结算一次。注入语音错误验证文字、画布和已结算用量保持正常。

详细时间与截图在 `private/reports/online-voice/installed.json` 和同目录图片中；这些是当前机器及网络的观测，不能保证所有网络延迟或服务持续可用。没有用真实 DeepSeek/Kimi/智谱凭据完成模型验收。

联网桥仅供 Electron 使用。Web 可选浏览器系统朗读或自行配置 TTS，不能把 Windows 的默认联网能力宣称为浏览器已经同样可用。麦克风识别配置与此次朗读改动独立，联网朗读并不等于联网识别。
