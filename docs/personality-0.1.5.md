# 0.1.5 智慧树人格修正

用户反馈普通身份提问“你是什么”得到“AI对话伙伴，套着智慧树的壳”的回答。根因是旧默认提示词将角色定义成“智慧树风格的AI伙伴”，此外旧回复会进入后续上下文强化这种表述。不是字体或气泡渲染问题。

本轮直接核对已审计英文GOTY固定对白及已哈希中文汉化覆盖层，重点键2、6、14、21、39：实用建议接荒唐补充、一本正经地多给一个无用提示、承认自己也不明白、设问后简短否定，以及并列句尾突然落到日常具体事物。原版不是不断用树根比喻的神秘老人，也不是逐项介绍自己性格的客服。

默认人格改为庭院里智慧树的第一人称。普通身份/问候保持角色；明确追问现实模型或接口则如实解释，不谎称真实植物、真人或官方程序。新增身份示例明确标为本应用写作示例，不冒充原版台词。其他话题保持事实与实用性；幽默不是每句强制任务，复杂代码按需展开，严肃困难话题不硬讲笑话。

每次默认人格请求从当前选择的语言资源抽取5个实际原版句式样例。中文使用已核对的中文覆盖层，英文使用本机英文GOTY；不在公开源码中复制游戏台词。固定施肥/随机对白仍独立由资源键渲染。

LocalStore.personaSettings在一个IDB事务中只升级与旧默认全文完全一致的provider.systemPrompt/personality记录，自定义与故意空白的提示词保持原样。新默认/恢复默认都采用同一个模板。默认人格的请求上下文排除旧的跳出角色自述，用户消息和普通技术讨论保留；聊天历史原记录不删除、不改写，不自动重试/重新消费LLM调用，不把服务商原始输出换成预制答案。

39项单元测试通过。tests/personality-browser.mjs检查实际浏览器请求、双记录旧默认迁移、中文来源样例、历史保留而请求排除旧出戏自述、自定义保留/恢复默认，以及单次请求精确用量。它使用明确标注的本地模拟模型，不能据此声称真实服务商已通过人格测试。tests/personality-cases.json包含36题及人工评分标准，尚未调用真实模型执行；不同模型仍需实际聊天评估，不承诺仅凭提示词百分之百复现原版幽默。
