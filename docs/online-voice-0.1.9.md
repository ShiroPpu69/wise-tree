# 0.1.9 更换免费联网语音来源

Windows 默认联网来源从微软 Edge Read Aloud 换成网易有道团队公开的 [Confucius4-TTS 体验服务](https://confucius4-tts.youdao.com/gradio)。入口来自[团队官方仓库](https://github.com/netease-youdao/Confucius4-TTS)，通过公开 Gradio API 调用，当前实测不需要登录或 API Key。不是微软接口的代理，不向用户收取语音调用费，没有付费或本地模型自动回退。

这是公开研究体验服务，不是承诺长期免费、无限量或持续可用的生产 SLA。可能排队、限流、修改或停服；失败保留文字与游戏，手动重试。禁止通过变换身份、绕过限额或共享密钥规避服务限制。

## 音色与隐私

三个阶段继续为 1–9 英尺儿童、10–49 英尺年轻、50 英尺起老年；原设置与自定义阈值保持。使用三份独立合成的短音色参考，保持每个阶段的音色依据。参考音频由千问官方 VoiceDesign 体验服务生成，文本均为“你好，我是智慧树。”，分别描述男童、年轻男性和老年男性；不克隆真实人物，也不是 GOTY 原版配音。

这些样本合计238722字节，不含推理模型。样本原始记录及 SHA-256 在 `private/reports/voice-source-research/references.json`；嵌入 `apps/desktop/voice-references.cjs`，打包时并入联网模块，排除重复文件。运行时不连接千问或 Hugging Face，仅向有道发送随包合成参考及当前片段文字。不发送整份聊天历史、长期记忆、模型密钥或用户录音。公开 Gradio 服务会缓存生成音频；不能承诺缓存私密或自动删除，界面已明确提示勿用于敏感文本。

中文、英文使用同一阶段参考做跨语言合成。语速在客户端播放时调整，音量仍由本机播放控制。文本流提前分句与下一句预取保留；同一时刻只播放一段，施肥及停止会取消本机请求并丢弃迟到结果，服务端已经接收的任务可能仍完成。

## 实现与验证

适配器 `apps/desktop/online-voice-source.cts` 固定有道域名。只接受已验证的 Gradio 缓存路径；忽略返回 URL，避免错误相对 URL 或向任意主机请求。请求禁用跳转和凭据，45秒上限，无自动重试；限制元数据、事件流和音频长度，检查 WAV 完整性，错误不回显远端文本。

56项单元测试通过，包括 SSE 字节拆分/CRLF、异常流、路径注入、WAV 校验、无凭据请求、取消及429不重试。`tests/youdao-voice-live.mjs` 使用真实公开测试文字验证三阶段中文和英文，首次测试完整片段耗时约0.8–2.4秒，仅代表本机当时网络。应用整体回归使用 `tests/online-voice-desktop.mjs`，LLM 为本地模拟 SSE，语音为真实有道服务；详细报告在 `private/reports/youdao-voice/`。

此前研究中，千问公开 VoiceDesign 生成三个样本成功，但额外 CustomVoice/Clone 调用返回无细节的 error 事件，不能确认具体原因，不适合作为已验证的替代运行源。CosyVoice 公共体验调用也失败，百度旧公开接口返回参数错误。未把这些候选来源包装成可用服务。

本次没有修改金币兑换、存档格式或游戏资源。浏览器没有新增有道请求桥，仍可选择浏览器系统音色或自配服务，不能宣称 Web 也已实现同样默认来源。真实 DeepSeek 与另一模型服务验收仍需用户本机凭据。
