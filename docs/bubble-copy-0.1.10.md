# 0.1.10 气泡复制与语音重播

游戏内气泡提供“复制”按钮，使用原版石头按钮纹理与现有补充中文字体。一次复制当前已收到的完整原文，不受滚动位置、可见行数或逐字显示进度影响；保留代码围栏、缩进、空行和特殊字符。流式生成中尚未收到的文字不会提前包含。施肥与空闲原版提示也可复制完整资源文本，英文界面显示 Copy。可 Tab 聚焦、Enter 激活；设置、历史、商店与演示界面不会露出可交互的气泡复制按钮。

Windows 使用经过发送窗口验证、只写不读的剪贴板 IPC，最多1048576个 UTF-16 单元；没有新增读取用户剪贴板接口。Web 使用标准 Clipboard API，权限被拒绝时显示可理解的错误，游戏及文字保留。操作系统/浏览器可能把换行转换为 Windows CRLF，这不会改变代码缩进或行结构。

## 语音修正

仍使用 0.1.9 网易有道公开体验源，不需要语音 Key。新增仅在当前应用内存中的 LRU 缓存：最多24个片段、8MiB，超限淘汰旧片段，退出后消失，不写入存档或聊天导出。已经成功合成且仍在缓存的片段可直接重播，不再次上传文字；阶段、语言、内容分别匹配，改变语速不必再次合成。删除任一聊天记录或清空历史时停止朗读并清空本机语音缓存。此前已上传到公开服务的内容不能由本机缓存清理保证删除。

取消合成时，等待共享音色样本上传的请求现在能立即退出；取消的旧请求不会误清理后来请求的有效样本缓存。已取消或迟到的音频不会播放，也不会写入语音缓存。公开语音服务排队、暂停或限流的限制仍在。

## 验证

61项单元测试通过，新增覆盖缓存容量/淘汰/清除、重播不联网、成长音色区分、取消迟到结果、共享上传取消竞态，以及所有目标高度的复制按钮布局。

`tests/bubble-copy-desktop.mjs` 在独立 profile 中调用本地模拟 LLM，用真实剪贴板校验短句、长代码、施肥后的原版资源台词、英文与键盘激活，验证三种窗口尺寸和非法 IPC 拒绝。`tests/bubble-copy-browser.mjs` 验证生产 Web、真实 Chrome 剪贴板 API 与拒绝权限后的降级；没有读取原有用户剪贴板。

`tests/online-voice-desktop.mjs` 继续实际联网语音回归，并额外检查完整重播后服务请求次数不增加。LLM 仍为夹具，不等于真实模型服务验收。详细结果见 `private/reports/bubble-copy/` 与 `private/reports/youdao-voice/`，以 packaged/installed 文件区分打包与安装后运行。

本次按 React 检查规范复核：复制在用户事件中执行，文本从 scene ref 即时读取；只在控件几何或显隐变化时更新 React 状态，不逐帧传输整段文本；有键盘名称与焦点样式，弹窗遮挡时隐藏；没有引入 UI 库或修改原版图像。
